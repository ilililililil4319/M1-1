## Ⅰ. 추진배경 및 필요성

원/달러 환율은 뉴스에서 매일 언급되지만, "지금 오르는 추세인지", "이 정도 변동이 평소보다 큰 건지"를 숫자 근거로 판단하기는 쉽지 않다. 대부분 헤드라인 몇 개에 의존해 감으로 판단하는 경우가 많다.

한국은행 경제통계시스템(ECOS)은 일별 원/달러 환율을 공개 API/파일로 제공한다. 이 데이터를 정제·분석하면 특정 구간의 상승/하락 추세, 변동성이 커진 시점, 월별 패턴 등을 수치로 확인할 수 있다.

이 프로젝트는 원/달러 환율 데이터를 시계열 분석하여 "관찰(그래프에서 확인한 사실)"과 "해석(가능한 원인 가설)"을 구분해 정리한 인사이트 리포트를 작성하고, 이를 기간별로 탐색 가능한 웹 대시보드로 확장하는 것을 목표로 한다.

분석 대상 기간과 데이터 출처를 명확히 밝히고, 결측치·이상치 처리 기준까지 투명하게 기록함으로써 누구나 같은 데이터로 같은 결론을 재현할 수 있도록 하는 것 또한 이 프로젝트가 지향하는 중요한 원칙이다.

## Ⅱ. 과제 목표 및 기대효과

- [ ] 결측치/이상치를 확인하고, 어떤 기준으로 처리했는지 설명할 수 있다.
- [ ] 이동평균, 변화율 등 시계열 기법을 왜/어떻게 적용했는지 설명할 수 있다.
- [ ] 그래프에서 확인한 사실(관찰)과 해석(가설)을 구분해 서술할 수 있다.
- [ ] AI(Claude, 코디세이 API)를 분석/해설에 활용하되, 최종 판단 근거는 스스로 설명할 수 있다.

**2) 기대효과**
① 뉴스 헤드라인이 아닌 데이터 근거로 환율 흐름을 판단하는 역량을 기른다.
② 데이터 정제 → 분석 → 시각화 → 웹 서비스화까지 이어지는 엔드투엔드 경험을 축적한다.
③ AI 도구를 검증 가능한 방식으로 활용하는 습관(AI 사용 로그 작성)을 기른다.

## Ⅶ. 오류 처리 설계

| 발생 단계 | 예상 원인 | 처리 방식 |
|---|---|---|
| 데이터 다운로드 실패 | ECOS API 응답 오류, 네트워크 연결 문제, 사내망/방화벽 차단 | 로컬에 미리 받아둔 CSV 백업본으로 대체하고, 오류 발생 시각과 응답 코드를 로그 파일에 기록한다 |
| 결측치 처리 시 | 공휴일·주말 등으로 특정 날짜의 환율 데이터가 누락 | 선형 보간(interpolate)으로 채우거나 전일 종가를 유지하며, 처리한 날짜와 방식을 REPORT.md에 표로 정리한다 |
| 코디세이 API 호출 실패 | 인증키 오류, 요청 한도(rate limit) 초과, 응답 지연 | 최대 2회 재시도 후에도 실패하면 "잠시 후 다시 시도해주세요" 안내를 표시하고, 실패 원인을 콘솔·로그에 기록한다 |
| 대시보드 기간 미선택 | 사용자가 기간 슬라이더를 조작하지 않고 바로 조회 | 기본값으로 최근 3개월 구간을 자동 표시하고, 화면에 안내 문구를 함께 노출한다 |
| 그래프 렌더링 실패 | 전달된 JSON 데이터 형식 불일치, 차트 라이브러리 로드 실패 | 콘솔 에러로 원인을 확인해 데이터 타입을 재검증하고, 실패 시 "그래프를 불러올 수 없습니다" 문구로 대체 표시한다 |
| AI 해설 코멘트 품질 이상 | 프롬프트에 전달된 데이터 형식 오류, 컨텍스트 길이 초과 | 프롬프트 템플릿과 입력 데이터를 재점검하고, 필요 시 구간 데이터를 요약해 전달한다 |
| 배포 후 동작 이상 | Vercel 환경변수 미설정, 정적 파일 경로 오류 | Vercel 배포 로그를 확인해 원인을 특정하고, 로컬에서 재현·수정한 뒤 재배포한다 |
