## Ⅰ. 프로젝트 개요

본 보고서는 M1-1 미션(AI 데이터 분석: 데이터 기반 트렌드 분석)의 최종 수행 결과를 정리한 문서다. 기획서에서 계획한 내용을 실제로 어떻게 구현했는지, 어떤 결과물이 나왔는지, 그 과정에서 어떤 시행착오가 있었는지를 증빙 화면과 함께 기록한다.

계획대로 한국은행 ECOS의 원/달러 매매기준율 데이터를 수집·정제하여 시계열 분석을 수행했고, 이를 바탕으로 분석 리포트(REPORT.md)를 작성했다. 또한 보너스 과제로 분석 결과를 기간별로 탐색할 수 있는 웹 대시보드를 구현하여 Vercel에 배포하고, 실제 배포 환경에서 AI 해설 기능까지 정상 동작하는 것을 확인했다.

기획서 단계에서 세운 계획과 실제 구현 사이에 달라진 점, 그리고 작업 중 발생한 오류와 해결 과정은 Ⅳ장에서 별도로 정리했다.

**주요 산출물**
- 분석 리포트 REPORT.md — 데이터 설명, 시계열 분석, 시각화 3종, 인사이트 3개, AI 사용 로그
- 분석 코드 notebook/analysis.ipynb 및 requirements.txt
- 웹 대시보드 (web/) — 기간 필터 + AI 해설 기능, Vercel 배포 완료
- GitHub 저장소 — 코드, 데이터, 문서, 증빙 스크린샷 전체 업로드

### 3) 인사이트 도출 — AI 활용 및 사실 검증

급등락일과 실제 사건(이란-미국 전쟁, 한국 비상계엄 등)의 연결 가설은 AI가 먼저 제시했으나, 그대로 받아들이지 않고 웹 검색으로 실제 사건 발생일을 직접 재검증한 뒤 REPORT.md에 반영했다.

특히 2026년 이후의 사건은 AI의 학습 데이터에 없는 내용이라 AI 스스로도 확신 없이 답하는 대신 먼저 검색을 거쳤고, 검색 결과와 데이터의 급등일(2026-03-03)이 실제 전쟁 발발일(2026-02-28)로부터 3일 뒤라는 점까지 교차 확인했다. 이 과정을 통해 AI가 제시한 가설을 결론으로 바로 쓰지 않고, 근거를 검증한 뒤에만 리포트에 반영한다는 원칙을 지켰다.

## Ⅳ. 오류 처리 이력 정리

작업 중 실제로 발생했던 오류와 해결 과정을 정리했다. 계획 단계(기획서 Ⅶ)에서 예상했던 오류 외에, 실제 구현 중에만 드러난 오류도 함께 기록한다.

| 오류 | 원인 | 해결 |
|---|---|---|
| Jupyter 커널 재시작 후 NameError | 커널 메모리 초기화로 이전 실행 결과(변수)가 사라짐 | "모두 실행"으로 처음부터 재실행 |
| data.json 파싱 실패 (NaN 관련) | 이동평균 초반 구간의 결측값이 표준 JSON에 없는 NaN으로 저장됨 | pd.notnull 처리로 NaN을 null로 변환 후 저장 |
| 대시보드 최저가가 0으로 표시 | Math.min() 계산 시 null 값이 0으로 취급됨 | 통계 계산 전 null 값을 배열에서 필터링 |
| Vercel 배포 시 "Python 프로젝트"로 오인식 | 저장소 루트에 requirements.txt, codyssey_api.py가 있어 Vercel이 오판 | Root Directory를 web으로 지정 |
| AI 해설 401 인증 오류 | Vercel 환경변수에 입력한 API 키 값 오류 | 환경변수 값 재확인 후 Redeploy |

## Ⅶ. 기타 — 소감 및 향후 개선 방향

데이터 정제 단계에서 결측치·이상치를 기계적으로 처리하는 것보다, "왜 그 값이 비었는지·왜 튀었는지"를 확인하는 과정이 훨씬 중요하다는 것을 체감했다. 특히 AI가 제시한 인과관계 가설을 그대로 믿지 않고 직접 검색으로 재검증하는 과정에서, AI 활용의 핵심은 "빠른 초안"이지 "최종 판단"이 아니라는 점을 다시 확인할 수 있었다.

대시보드 배포 과정에서는 로컬과 배포 환경의 차이(파일 프로토콜, 서버리스 함수 실행 여부, 환경변수 반영 시점)로 인한 오류를 여러 차례 겪었는데, 이 과정에서 오류 메시지를 정확히 읽고 원인을 좁혀나가는 디버깅 습관을 기를 수 있었다.

**향후 개선 방향**
- 환율에 영향을 주는 다른 변수(금리차, 유가, 수출입 지표)를 함께 분석해 인과관계 해석의 근거를 보강
- 대시보드에 로트/구간별 비교 기능을 추가해 여러 기간을 동시에 비교할 수 있도록 확장
- 부정확한 AI 해설 대비, 프롬프트에 신뢰구간이나 근거 데이터 범위를 함께 명시하도록 개선
